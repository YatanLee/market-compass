# Release 0.2 — React and TypeScript

The production UI now runs on locally bundled React with strict TypeScript, and the backend, fixtures and regression tests use strict TypeScript. The server continues to bind only to 127.0.0.1:4187. Vite development runs on 4188 with a fixed local API proxy.

Validation on 2026-10-11: production build, strict source/test/client typechecks and 27 regression tests passed. Independent QA confirmed that the new client CSV parser is the parser exercised by tests. Independent review examined API security, source provenance, escaped rendering and the no-execution boundary. The PM verified a React SMA backtest against the existing synthetic baseline, the corrected demonstration source date, and a 390-by-844 mobile layout without horizontal overflow or console warnings/errors.

Vite cleans only its dedicated generated dist/ui output during rebuild, retaining the separate compiled server directory. Current output contains the index and only its current CSS/JS bundles. Original 0.1 MJS/public sources remain temporarily as inactive migration references; build/start/test scripts select TypeScript and React paths.

Real source availability and financial/research limitations from the first release remain in force. This migration adds no demonstrated prediction advantage. Full browser-native CSV file selection remains a documented manual check; parser and local API behavior are tested.
