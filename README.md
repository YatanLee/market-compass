# Market Compass

Market Compass 是以繁體中文呈現的本機投資研究工具，用於查看市場資料、觀察事件與比較策略。它不連接券商、不處理金流或下單，也不保證收益；回測結果不代表未來表現。

## 在本機啟動

需求：Node.js 24 或更新版本。執行期不需安裝第三方套件。

在 PowerShell 執行：

```powershell
Set-Location 'D:\Project\market-compass'
npm start
```

接著在瀏覽器開啟 <http://127.0.0.1:4187>。按 Ctrl+C 停止伺服器。

執行測試與程式檢查：

```powershell
npm test
npm run check
```

## 資料與限制

示範內容使用合成資料，不代表即時行情或真實事件。歷史價格 CSV 必須使用精確標頭 `date,close`，日期為 ISO 格式，資料依日期嚴格遞增且不重複，收盤價必須是正數；檔案需包含 100 至 5,000 筆資料列。匯入資料會由本機伺服器在記憶體中處理，不會上傳至外部服務。基金研究以淨值為基礎，資料頻率、申贖與配息處理可能限制比較結果。

即時來源包括 TWSE、GDELT、美國聯準會官方演說 RSS，以及白宮官方談話索引；每次更新都由使用者手動觸發。來源可能無法使用或只回傳部分資料，介面會呈現各來源狀態與錯誤。新聞報導不能當成原始發言或社群討論量；美股、基金與社群資料來源尚未連接。事件標題保留來源原文語言，介面操作與控制項使用繁體中文。成本、滑價、樣本區間與資料品質會影響回測，歷史結果不代表未來收益。

使用者匯入資料不應提交至版本庫。此工具僅供研究，不提供個人化投資配置或財務建議，也不會發出交易指令。
